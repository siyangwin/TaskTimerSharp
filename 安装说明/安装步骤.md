# 安装 / 卸载与管理 Windows 服务

> ⚠️ **所有操作请以「管理员身份」运行，否则会因权限不足而失败。**

## 第一步：以管理员身份开启终端

- 在开始菜单搜索 **PowerShell** 或 **CMD**
- **右键** → 选择 **「以系统管理员身份运行」**

## 第二步：切换到 .NET Framework 目录

```bash
cd C:\Windows\Microsoft.NET\Framework64\v4.0.30319\
```

## 第三步：执行安装或卸载

### CMD（命令提示符）

```cmd
:: 安装
installutil.exe E:\xxxxx\TimerProjectByWindowsService.exe

:: 卸载
installutil.exe /u E:\xxxxx\TimerProjectByWindowsService.exe
```

### PowerShell

> ⚠️ **PowerShell 不会自动运行当前目录下的程序，必须加上 `.\` 前缀：**

```powershell
# 安装
.\installutil.exe E:\xxxxx\TimerProjectByWindowsService.exe

# 卸载
.\installutil.exe /u E:\xxxxx\TimerProjectByWindowsService.exe
```

## 第四步：管理服务

以下命令中的 `TimeProject` 请换成你实际的服务名称。

### 启动 / 停止

```cmd
:: 启动服务
net start TimeProject

:: 停止服务
net stop TimeProject
```

### 暂停 / 恢复

```cmd
:: 暂停服务
net pause TimeProject

:: 恢复被暂停的服务
net continue TimeProject
```

## 设置服务启动方式

```cmd
:: 自动启动
sc config TimeProject start= auto

:: 手动启动
sc config TimeProject start= demand

:: 停用
sc config TimeProject start= disabled
```

> 💡 `sc config` 的 `start=` 与值之间**必须有一个空格**（例如 `start= auto`），这是 `sc.exe` 的语法要求，漏掉空格会导致命令失败。

## 打开「服务」管理窗口

```cmd
services.msc
```

## 常见问题

| 错误信息 | 原因 | 解法 |
|---------|------|------|
| `is not recognized as the name of a cmdlet...` | PowerShell 中未加 `.\` | 改用 `.\installutil.exe` |
| `SecurityException: 不可访问的日志: Security` | 未以管理员身份运行 | 右键 → 以系统管理员身份运行 |
| `System.ComponentModel.Win32Exception: 拒绝访问` | 未以管理员身份运行 | 同上 |
