# 安裝 / 卸載 Windows 服務

> ⚠️ **所有操作請以「管理員身分」執行，否則會因權限不足而失敗。**

## 第一步：以管理員身分開啟終端

- 在開始選單搜尋 **PowerShell** 或 **CMD**
- **右鍵** → 選擇 **「以系統管理員身分執行」**

## 第二步：切換到 .NET Framework 目錄

```bash
cd C:\Windows\Microsoft.NET\Framework64\v4.0.30319\
```

## 第三步：執行安裝或卸載

### CMD（命令提示字元）
```cmd
:: 安裝
installutil.exe E:\xxxxx\TimerProjectByWindowsService.exe

:: 卸載
installutil.exe /u E:\xxxxx\TimerProjectByWindowsService.exe
```

### PowerShell

> ⚠️ **PowerShell 不會自動執行當前目錄下的程式，必須加上 .\ 前綴：**

```powershell
# 安裝
.\installutil.exe E:\xxxxx\TimerProjectByWindowsService.exe

# 卸載
.\installutil.exe /u E:\xxxxx\TimerProjectByWindowsService.exe
```

## 常見問題

| 錯誤訊息 | 原因 | 解法 |
|---------|------|------|
| `is not recognized as the name of a cmdlet...` | PowerShell 中未加 `.\` | 改用 `.\installutil.exe` |
| `SecurityException: 不可访问的日志: Security` | 未以管理員身分執行 | 右鍵 → 以系統管理員身分執行 |
| `System.ComponentModel.Win32Exception: 拒绝存取` | 未以管理員身分執行 | 同上 |



所有操作，请在管理员模式运行，否则可能不成功

打开 .NET Framework

cd C:\Windows\Microsoft.NET\Framework64\v4.0.30319\

安装 运行 你的服务 EXE的路径
installutil.exe E:\xxxxx\TimerProjectByWindowsService.exe


卸载 运行 你的服务 EXE的路径
installutil.exe /u E:\xxxxx\TimerProjectByWindowsService.exe

启动服务
net start TimeProject 

关闭服务
net stop TimeProject 

将服务设为自动启动
sc config TimeProject start= auto

将服务设为手动启动
sc config TimeProject start= demand

打开服务窗体

CMD >  services.msc


启动服务：net start 服务名
停止服务：net stop 服务名暂停服务：net pause 服务名
恢复被暂停的服务：net continue 服务名
禁用服务：sc config 服务名 start=disabled
将服务设为自动启动：sc config 服务名 start= auto
将服务设为手动启动：sc config 服务名 start= demand
